# V5 自動收件：Google Apps Script

本資料夾已包含可上傳到 Google Apps Script 的程式。

- `Code.gs`：限時邀請、管理驗證、一次性提交、暫存與刪除
- `Index.html`：心評人員及家長／教師的網頁
- `Bank.gs`：**公開示範題庫（非正式量表）**

## 啟用流程

1. 建立私人 Google 試算表，記下網址中的試算表 ID。
2. 從試算表選 **擴充功能 → Apps Script**，將 Code.gs 貼入預設程式檔。
3. 建立 HTML 檔 `Index`，貼入 Index.html 全部內容。
4. 建立指令碼檔 `Bank`，貼入 Bank.gs 全部內容。**原始量表題幹只能由有使用權限者從私人套件安裝，不得放進公開 GitHub。**
5. 在 Apps Script **專案設定 → 指令碼屬性** 設定：
   - `SHEET_ID`：私人試算表 ID
   - `ADMIN_PASSWORD_SETUP`：至少14字、由管理者自訂的密碼
6. 在編輯器執行 `setupSystem_` 一次，完成 Google 授權。程式會建立工作表、每日清理排程，轉存密碼雜湊並刪除初始密碼屬性。
7. **部署 → 新增部署 → 網頁應用程式**，執行身分選「我」，存取對象選「任何人」（如帳戶政策允許）。部署網址即為心評入口與問卷分享連結的根網址。
8. 請只用**虛構資料**完成跨裝置完整測試。

### 特別注意

- GitHub Pages 本身無法自動安全收件；真正儲存答案的是 Google Apps Script 和私人 Google 試算表。
- 本目錄 Bank.gs 是**示範**；尚未提供正式原始144題，請勿施測。
- 尚未取得量表逐題配分及個資安全的正式驗收，因此**不提供計分及鑑定結果**。
- 管理者在下載資料後可手動刪除；已提交資料預設7天清除，仍須評估 Google 備份保存規則及服務配額。
- 請勿在公開儲存庫、聊天室或前端 HTML 存放管理密碼、學生資料。
